花店装修面板 — 下半屏全宽底栏交互原型（仅策划/美术参考，不入 minigame）

原型图：decoration_panel_bottom_sheet_prototype_nb2.png
NB2 提示词（仓库内）：game2D_huahua/docs/prompt/decoration_panel_bottom_sheet_prototype_nb2_prompt.txt

设计要点
1. 布局：整块底栏占屏幕高度约 50%～55%，左、右、下三边与屏幕边缘贴齐（无外边距），仅顶边与上半屏场景分界（可微弧 + 顶影）。
2. 视觉：去掉现行厚重金边奶油底板；顶条改为更鲜亮的桃杏/珊瑚渐变（避免大块灰绿、薄荷绿——与装修页草地撞色系）；主区暖象牙偏微桃色，分割线暖玫瑰灰。与合成线/装修等面板统一：保留轻微立体（整体上投阴影、顶沿内高光、内容区微内阴影、顶条单线香槟金细描边、Tab/卡片小浮雕与卡下软阴影），避免完全扁平，但勿回到厚重双金框。
3. 结构：顶栏标题「花店装修」+ 关闭；其下收集进度「已收集 x/y」+ 细进度条；左侧竖向分类 Tab；右侧 2 列可滚动家具/风格卡网格（与现逻辑一致）。
4. 交互：点击遮罩上半仍可关闭（与现 DecorationPanel 一致）；底栏内滚动、点卡逻辑不变，仅改几何与素材。

定稿后：按 game-art-asset-flow 拆切图或程序矢量重绘，再写入 TextureCache / DecorationPanel 常量。
